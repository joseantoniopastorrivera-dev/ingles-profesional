# 🇬🇧 Inglés Profesional

Apuntes, vocabulario técnico y actividades del módulo de Inglés Profesional de 2º DAM / Professional English for software developers: technical vocabulary, reading, writing and speaking coursework.

---

## 🗂️ Estructura del Repositorio

Una carpeta por sesión, con el mismo número que en el aula virtual y los documentos de clase en minúsculas con guiones.

* **`session-1-…/`**: Session 1.
* **`session-2-…/`**: Session 2.

---

## 🛠️ Contenidos
* **Destrezas**: Reading, Writing, Listening, Speaking.
* **Ámbito**: Inglés técnico aplicado al desarrollo de software.
* **Control de Versiones**: Git / GitHub.
